# Prompt Claude — Revisão antes do código

## Tarefa

Revise todos os documentos, aponte inconsistências, decisões pendentes e riscos antes de implementar.

## Antes de codar

- Leia os documentos do pacote.
- Liste arquivos que serão criados/alterados.
- Aponte decisões pendentes.
- Não fuja da stack definida.
- Não introduza dependências grandes sem justificar.

## Entrega esperada

- Código organizado.
- Comandos de setup.
- Variáveis de ambiente necessárias.
- Testes mínimos.
- Critérios de aceite verificados.
